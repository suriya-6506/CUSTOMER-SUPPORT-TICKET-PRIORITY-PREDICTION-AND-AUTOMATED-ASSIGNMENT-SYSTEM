# CUSTOMER-SUPPORT-TICKET-PRIORITY-PREDICTION-AND-AUTOMATED-ASSIGNMENT-SYSTEM
Customer Support Ticket Priority Prediction and Automated Assignment System using Agentforce.
This project uses Salesforce, Agentforce, and Flow Automation to analyze customer support ticket descriptions, automatically classify ticket priority as High, Medium, or Low, create urgent tasks for high-priority tickets, and assign them to the appropriate support agent.
